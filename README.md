# 📄 Indian Patent Journal Extractor

A Python desktop application that extracts structured patent data from Indian Patent Office Journal PDFs and exports it to Excel.

---

## ✨ Features

- 📄 Extracts patent data from Indian Patent Office Journal PDFs
- 📊 Exports extracted data to Excel (.xlsx)
- 📈 Live progress bar with page counter
- 📂 One-click "Open Output Folder"
- 🖥️ Modern CustomTkinter GUI
- ⚡ Standalone Windows executable
- 🎨 Custom application icon

---

## 🛠️ Technologies Used

- Python 3
- CustomTkinter
- PyMuPDF (fitz)
- OpenPyXL
- Regular Expressions (Regex)
- PyInstaller
